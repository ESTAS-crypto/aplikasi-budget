# Suara tema Kucing Manis

27 file: 23 suara dengan NAMA FILE SAMA seperti set Pasar Malam (audio/), ditambah meow_1, meow_2, meow_3, purr.
Dibuat dari nol dengan sintesis (skrip: synth_kucing.py), bukan sampel. Belum didengarkan oleh pembuatnya; nilai di telinga dan minta penyesuaian.

## Karakter
- Timbre kotak musik (partial 1x, 2,76x, 5,4x) menggantikan kalimba kayu; nada tetap pentatonik C.
- Tick roda jadi "pat" tepukan telapak kaki dengan denting kecil.
- Meong disintesis dengan kontur nada naik lalu turun (sekitar 735 -> 900 -> 550 Hz pada meow_1) dan formant yang bergerak seperti mulut membuka.
