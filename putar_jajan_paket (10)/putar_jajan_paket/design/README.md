# Desain Putar Jajan

- screens/: 21 gambar acuan (nomor sama dengan judul layar di kanvas desain). Ini pratinjau statis pada momen animasi sudah selesai.
  PENTING: font di gambar adalah font pengganti karena dirender tanpa internet. Font aslinya Bricolage Grotesque (500/700/800); ukuran teks di aplikasi mengikuti angka di source, bukan lebar teks di gambar.
